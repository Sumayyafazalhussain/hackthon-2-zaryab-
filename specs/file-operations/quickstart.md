# Quickstart: File Operations

This document provides a quickstart guide for using the File Operations feature.

## Prerequisites

- Python 3.12 or higher.

## Usage

### Read a file

```bash
python main.py read <file_path>
```

### Write to a file

```bash
python main.py write <file_path> "<content>"
```

### Delete a file

```bash
python main.py delete <file_path>
```
