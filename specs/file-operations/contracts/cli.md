# CLI Contracts: File Operations

This document defines the command-line interface for the File Operations feature.

## Commands

### `read`

- **Description:** Reads the content of a file and prints it to the console.
- **Usage:** `python main.py read <file_path>`
- **Arguments:**
    - `file_path`: The path to the file to read.

### `write`

- **Description:** Writes content to a file.
- **Usage:** `python main.py write <file_path> <content>`
- **Arguments:**
    - `file_path`: The path to the file to write to.
    - `content`: The content to write to the file.

### `delete`

- **Description:** Deletes a file.
- **Usage:** `python main.py delete <file_path>`
- **Arguments:**
    - `file_path`: The path to the file to delete.
